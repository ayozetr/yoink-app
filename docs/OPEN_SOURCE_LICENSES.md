# Open-source licenses

Yoink is built on open-source software. Listed below are Yoink's direct
dependencies and their licenses — the libraries it uses directly; each in turn
pulls in further open-source libraries under the same permissive licenses.

## Bundled media tools

- **ffmpeg / ffprobe** — LGPL v3 (built minimal; see THIRD_PARTY_LICENSES.md)
- **yt-dlp** — The Unlicense (public domain) — the download engine
